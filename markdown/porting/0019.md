# 支援事例 No.19

## 種別

移植

## 課題・問題点

aenet( http://ann.atomistic.net/ ) およびそのエネルギー評価関数を使用したLAMMPS( https://github.com/HidekiMori-CIT/aenet-lammps )の「富岳」での移植と aenetとそのエネルギー評価関数を使用したLAMMPSの「富岳」での実行支援
移植・環境適応

## 分類

移植支援、実行支援

## 支援内容

「富岳」上で、aenetとそのエネルギー評価関数を使用したLAMMPSの正常終了を確認し、計算資源を有効に活用するaenetの実行方法を調査した。

## 支援結果

aenetはスレッド並列化されてないため、フラットMPIの実行が、実行時間の観点からも、計算資源の有効利用の観点からも優位。さらに、高速型通信モードによりAllreduceの平均実行時間を短くすることができた。
