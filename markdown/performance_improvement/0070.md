# 支援事例 No.70

## 種別

性能改善

## 課題・問題点

DEMをベースとして混錬解析用に開発した独自コードの並列化時の実行性能が低い。
スレッド並列・通信最適化
コード構造の改善
移植・環境適応

## 分類

性能改善

## 支援内容

基本プロファイラを用いて、インバランス・高コスト部を洗い出し、以下の改善策を試行した。
・配列初期化部分の改善（不必要な初期化の削除）
・隣接通信の高速化
・簡易ロードバランサーの検討
最後に、詳細プロファイラによる分析により、上記の改善策による効果を確認した。

## 支援結果

・初期化部分の削除と隣接通信（MPI_SEND/RECV）の修正（改善(1)）
－64並列時（タイムステップ：0.05）
オリジナル：785秒（初期化部分の約570秒を含む）
改善(1)後：98秒
初期化部分も含め8倍程度の高速化を達成
・簡易ロードバランサーを試した結果（改善(2)）
－64並列時（タイムステップ：0.5）
改善(1)：1,531秒
改善(2)：1,209秒
ロードバランサーの効果でさらに２割程度の時間短縮を確認
