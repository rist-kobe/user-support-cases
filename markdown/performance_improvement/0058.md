# 支援事例 No.58

## 種別

性能改善

## 課題・問題点

以下の支援をお願いしたい。
1)固有値ライブラリをLAPACKに置き換え
2)大規模データによるプログラムの性能評価
ライブラリ活用

## 分類

性能改善

## 支援内容

・固有値ソルバをMillerからLAPACKに変更した。
・基本プロファイラ（fipp）を用いて、ホットスポットを3ルーチン特定し、OpenMPによる並列化及びコンパイラによる自動並列化の実施。

## 支援結果

・固有値ライブラリの変更により、性能はやや劣化したが、可搬性が向上した。
・性能情報
オリジナル（固有値ライブラリ：Miller）　95.79秒(1スレッド実行)→21.24秒(8スレッド実行)
変更後（固有値ライブラリ：LAPACK） 109.19秒(1スレッド実行)→23.10秒(8スレッド実行)
