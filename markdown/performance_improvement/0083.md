# 支援事例 No.83

## 種別

性能改善

## 課題・問題点

「富岳」向けDFTB+ (v22.1)の移植と基礎性能の調査。加えてDFTB+におけるメタダイナミックス計算で必要となる外部ライブラリとしてPLUMED2 (v2.8)の移植。
コード構造の改善
移植・環境適応
ライブラリ活用

## 分類

性能分析・
性能改善

## 支援内容

DFTB+ (v22.1)およびPLUMED2 (v2.8)を富士通コンパイラを利用して「富岳」向けに移植した。 利用者データを用いて、DFTB+とPLUMED2を連携させた計算設定 (メタダイナミックス)について動作確認と性能評価を実施した。
DFTB+についてチューニングを実施した。主な内容は次の3点:
(i) 配列組み込み関数(spreadなど) の陽なループ処理への書き換え
(ii) インライン展開
(iii) OpenMPのcollapseの削除 (診断レポートの指示)
MPI+OpenMPハイブリッド並列におけるスケーラビリティ向上に寄与する実行時設定を調査した。

## 支援結果

富士通コンパイラの障害や言語規格対応を調査し、DFTB+の「富岳」向け移植用パッチを作成した。
DFTB+およびPLUMED2について、ソース同梱の回帰テストをパスすることを確認した。
逐次計算において、オリジナルから3.3倍の速度向上を得た。
スケーラビリティについて、ラージページの設定 (XOS_MMM_L_ARENA_LOCK_TYPE=0による並列領域内動的メモリ確保に伴う排他的処理の回避
※
)、ロードインバランス緩和 (OMP_SCHEDULE=”dynamic,1”)、DFTB+の入力におけるScaLAPACK向け設定を適用・調整することで、オリジナルでは並列計算で遅くなっていた問題を解消した。利用者データで48コア (2mpi x 24omp) までスケールすることを確認した。
