# 支援事例 No.3

## 種別

性能改善

## 課題・問題点

「京」1万ノードを超える大規模利用の実績がないため、大規模時の利用法の相談およびその性能評価と、多数の変数とその引用関係が複雑な積分計算の計算結果に問題があり、その調査方法と回避策について
データ構造の改善
実行支援・動作検証

## 分類

インバランスの改善

## 支援内容

・性能分析の結果、データの分配方法によるインバランスが高並列時に性能を阻害することを確認した。インバランスが発生しないデータ配置（組合せ）を提案した。
・積分計算部の異常結果は、コンパイラの最適化に依存していることを確認。適切な最適化オプションを提案。
・コンパイラの障害情報は、「京」開発部門にフィードバック。

## 支援結果

・インバランスを解消させた結果、実行効率は11%から24%まで向上と、2倍強の高速化を実現。
・障害が生じる当該計算部分のみ、最適化レベルを下げ、正常な計算結果となることを確認した。
・後日、コンパイラの障害が修正された。
