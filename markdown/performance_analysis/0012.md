# 支援事例 No.12

## 種別

性能分析

## 課題・問題点

「京」での性能評価、具体的には、スレッド並列、MPI 並列の評価方法、CPU 性能の評価方法を知りたい。大規模化を検討しており、性能分析結果、問題があれば、その対策について
ソフトウェア評価

## 分類

通信の隠ぺい検討

## 支援内容

性能評価方法を説明。通信を隠ぺいするためのコーディング部分において、通信を開始させるトリガーを入れる改善方法を提案。更に大規模化した場合の課題として、使用メモリの増大、実行時間の増大について説明。

## 支援結果

通信開始トリガー（MPI_TEST）が実装された結果、実行時間は37%短縮され、高速化を実現。大規模化では対応策を利用者が検討中。
