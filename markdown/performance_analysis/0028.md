# 支援事例 No.28

## 種別

性能分析

## 課題・問題点

ノード間に著しいインバランスが見られる場合の性能改善について
ソフトウェア評価

## 分類

性能分析

## 支援内容

・対象プログラム（FFV-C v2.3.14）を「京」にインストール。
・テストデータを用いた並列実行（64プロセス8スレッド）と性能プロファイルの取得、及びその分析を実施。

## 支援結果

性能分析により判明した以下の改善点は、次年度以降で対応予定。
1)コード解析により、MPI通信前後にあるパック・アンパックがスレッド並列化されていないこと
2)今回のデータは1次元領域分割を採っているために細分化しても境界面積が変わらないこと
3)全実行時間の1/3を要しているマルチスレッド化されたSORループが演算量から推測される時間より1～2桁多くなっていること
