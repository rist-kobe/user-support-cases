# 支援事例 No.20

## 種別

性能分析

## 課題・問題点

プログラムFIESTAについて、単体性能が十分か、チューニングの余地があるのか、性能に問題が無いか、調査をお願いしたい。
I/O・メモリ最適化
ソフトウェア評価

## 分類

単体性能の分析

## 支援内容

主たる演算部分であるCG法のサブルーチンに対して性能分析を行った。また演算数を数え、理論的な限界性能を求めた。

## 支援結果

CG法の演算性能はピーク比の8%であった。またメモリスループットも70%に達しておりほぼ限界性能であることが分かった。
この演算部分の要求B/Fは4であることから理想限界性能はピーク比9％であり、ほぼ限界性能に達していることが分かった。
