# 支援事例 No.25

## 種別

性能分析

## 課題・問題点

Particle in cellコード（Fortran)をOpenMP+MPIによるハイブリッド並列を行っている。性能上問題ないのか、もし改善点があれば教えてほしい。
ソフトウェア評価

## 分類

性能評価と分析

## 支援内容

fippによるホットスポットの特定と、fappによる詳細な性能分析を行った。分析の結果、MPIによる通信時間は少なく、メモリアクセス時間も大きくないが、演算器の空きを待つ時間が多いことが分かった。また、ループ長は短かったが、コンパイラによる最適化により、適切な実行性能が出ていた。

## 支援結果

コンパイラの最適化に加え、以下の最適化を追加した。
１．不変式の除去
２．未利用のデータの除去
３．アンロール
４．定数「０」の掛け算の除去
しかし、コンパイラの最適化が十分なされており、追加した最適化による改善の効果は少なかった。そのため、オリジナルコードのままで十分と判断した。
