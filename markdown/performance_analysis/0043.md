# 支援事例 No.43

## 種別

性能分析

## 課題・問題点

①3x3tofu、4x4tofuを使用したFFTの評価
従来（10万ノードでの実行）を超えるノード数（全系実行）で、性能を確保できるかを確認する
②連続ジョブ実行のI/O
同一ディレクトリへのI/O(上書き)時の非同期 close on 設定において連続ジョブを実行 (シェル中で mpiexec を繰り返す）する場合のデータ不整合問題の調査・解決
移植・環境適応

## 分類

性能分析

## 支援内容

①3x3tofu、4x4tofuを使用したFFTの評価
全系を想定した規模までnodeブロック(FFTを実行するnodeの集合)を拡張するための汎用的な方式の検討。
②連続ジョブ実行のI/O
非同期 close on 設定の評価。
③全系規模サポート
全系規模実行に向けた規模でのnodeブロックの最適な３次元形状を生成するnodeブロックの拡張方式を提案。

## 支援結果

・提案したnodeブロック拡張方式を用いたFFTを含む壁面乱流場の直接数値計算の結果（性能面）を支援依頼者が論文としてまとめている。
・全系規模実行に向けた規模で、提案したnodeブロックの３次元形状を採用した「富岳」全系規模実行課題が採択され、支援員として全系規模実行をサポートした。
