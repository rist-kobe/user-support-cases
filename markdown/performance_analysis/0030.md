# 支援事例 No.30

## 種別

性能分析

## 課題・問題点

GPUを有するHPCI計算基盤の利用を検討している現有コードの性能について
移植・環境適応
GPU対応

## 分類

性能分析

## 支援内容

RISTが保有するGPUマシンを用いて、性能分析を行った。利用者コードに実装されたマルチグリッド法を用いた反復法ソルバから多数回呼び出される、演算量の少ない処理について重点的に調査した。

## 支援結果

ソルバ内から呼び出される、演算量の少ない処理のオーバヘッドが、処理の実行時間よりも大きいことを確認した。カーネル融合が有効と判断し、その実装例と性能評価例を示した。
