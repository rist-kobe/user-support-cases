# 支援事例 No.11

## 種別

性能分析

## 課題・問題点

並列数を256に増やすと性能が低下し、通信時間が増加している理由を知りたい。特に通信特性について
コード構造の改善

## 分類

通信時間増加の調査

## 支援内容

通信性能を評価したところ、通信には問題がなく、データに偏りが生じた結果、演算のインバランスにより性能が劣化していることを確認。インバランスの原因を利用者と究明した結果、粒子の初期設定の不具合に起因する事を特定。

## 支援結果

利用者が不具合を修正。この結果、256並列での性能低下は解消。
