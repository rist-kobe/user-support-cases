# 支援事例 No.13

## 種別

性能分析

## 課題・問題点

PC クラスタを使った512プロセスでの実績があるが、「京」での実績が無いため、「京」での並列性能に問題が無いか、また、更なる大規模実行に問題が無いか、について
ソフトウェア評価

## 分類

並列性能の調査

## 支援内容

大規模実行に不適な小さいデータサイズのため、並列性能調査ができないことを指摘。単体性能の評価は、SIMD化、ソフトウェアパイプライニング化の促進を提案。ただし、Fortran90のポインタ変数を多数利用しているため、コンパイラによる最適化が困難な点を指摘。

## 支援結果

大規模実行に妥当な規模のデータで調査予定。SIMD化、ソフトウェアパイプライニング化により、6%性能向上。
