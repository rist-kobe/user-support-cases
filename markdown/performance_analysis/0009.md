# 支援事例 No.9

## 種別

性能分析

## 課題・問題点

単体性能においてチューニングの余地があるのか、大規模化に向けて並列のスケーラビリティに問題ないかについて
スレッド並列・通信最適化

## 分類

大規模の性能調査

## 支援内容

・性能分析を、演算性能、通信性能、I/Oに分離し分析を実施。I/Oは、初期および終了処理時のみ実行されていることを確認し、評価の対象外。
・一部、スレッド並列化されてないルーチンを特定。ループの作業変数が阻害要因で、プライベート化指定、および指示行による並列化促進の対策を提案。

## 支援結果

・スレッド並列化促進で、当該ルーチンは、8スレッドで約8倍に、性能改善。
・MPI並列のスケーラビリティを4点（16,128,1024,8192）で実測評価。演算部分、通信部分、それぞれ大規模で問題にならないことを確認し、利用者に報告。

## 支援タグ

スレッド並列・通信最適化

## 技術タグ

Communication, IO, MPI, OpenMP, PerformanceAnalysis, Scalability
