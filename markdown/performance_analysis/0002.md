# 支援事例 No.2

## 種別

性能分析

## 課題・問題点

PC クラスタと「京」で実行したが、「京」では途中から計算結果が変わり収束しないため、原因調査。
移植・環境適応
実行支援・動作検証

## 分類

計算結果の診断

## 支援内容

PCクラスタと「京」の実行環境（ソルバー）が違っていた。同一ソルバーをPCクラスタ上で実行した結果、PCクラスタにおいても収束しないことを確認。

## 支援結果

結果の違いは、工学的に許容範囲内と判断されるため、「京」用に並列化したソルバーを用い、収束しないデータを除いて計算。

## 支援タグ

移植・環境適応, 実行支援・動作検証

Porting, Solver
