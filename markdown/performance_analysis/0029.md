# 支援事例 No.29

## 種別

性能分析

## 課題・問題点

ポスト処理プログラムの実行において、ランク０が代表してすべのデータをファイルに出力して（ロードインバラスが起きて）おり、今後計算規模を大きくする際に必須となる、インバランスの解消について
I/O・メモリ最適化

## 分類

性能分析

## 支援内容

MPI-IOを用いて各プロセスが手分けしてデータを出力することにより、時間を短縮することを考える（出力先は共通の単一ファイル）。 MPI_ALLREDUCEを用いる方法（手法(1)）と派生データ型を用いる方法（手法(2)）を試行した。また、簡単な出力プログラムを作成し、MPI-IOによる出力テストを行った。

## 支援結果

手法(1)はALLREDUCEに、手法(2)は派生データ型の出力に時間がかかり、高速化には至らなかった。出力テストでは、一定以上の出力データ量でMPI-IOによる加速が見られた一方で、派生データ型の元となるデータレイアウトの分割数が大きいほど出力に時間がかかることがわかった。引き続き、分割数の大きい派生データ型を用いない手法を検討予定。
