# 支援事例 No.17

## 種別

性能分析

## 課題・問題点

4,096core を用いた実行時にスケーラビリティが低下する原因について
ソフトウェア評価

## 分類

並列性能の分析

## 支援内容

性能分析ツールでは原因箇所を特定出来なかったため、ループ1回転毎の実行時間をタイマー計測し、詳細に分析を実施。その結果、原因が初期処理のI/Oにあると特定

## 支援結果

スケーラビリティ低下は初期処理のみであり、実データでの実行において、影響は無視できる事が判明し、プロダクトランに入った。
