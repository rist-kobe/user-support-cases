# 支援事例 No.27

## 種別

性能分析

## 課題・問題点

独自の修正を行ったQuantum ESPRESSOのv6.1について
1)旧バージョンと比較して性能が劣化した件
2)フラットMPIとMPI/OpenMPハイブリッド並列の性能評価
移植・環境適応
ソフトウェア評価

## 分類

性能評価

## 支援内容

1)提供された入力データに対して動作確認と性能評価
コンパイルオプションを変更し、結果確認と性能評価を行った。それらの結果に基づいて適切なコンパイルオプションを確定させた。
2)ジョブの最適な実行方法のノード数・スレッド数の評価
ノード数やスレッド数を変えてジョブを実行し経過時間を測定し、ジョブの最適な実行方法と、そのノード数・スレッド数を評価した。

## 支援結果

1)最適なコンパイルオプションを選んだが、実行ノード数によって、収束回数が異なる場合があることが確認された。この問題は、利用者側で判断することとなった。
2)プロダクトランに使う原子数規模（100原子弱）では、ハイブリッド並列よりもフラットMPIの32ノード（256プロセス）か48ノード（384プロセス）での実行が適していた。
