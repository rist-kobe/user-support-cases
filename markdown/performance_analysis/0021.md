# 支援事例 No.21

## 種別

性能分析

## 課題・問題点

プログラム conquest で、主たる演算箇所の実行性能を測ってほしい。また性能分析ツールの使い方を教えてほしい。
さらに並列性能を阻害しているボトルネックを分析・改善する方法を知りたい。
ソフトウェア評価

## 分類

単体性能および並列性能の分析

## 支援内容

(1)性能分析方法として基本プロファイラー(FIPP)、詳細プロファイラー(FAPP)、精密PA、MPI統計情報等の性能分析ツールによる性能情報の収集方法とその計測結果を提供
(2)並列性能を可視化するツールVampirTraceによるデモを実施

## 支援結果

主たる演算箇所の性能は2%弱であった。この箇所のB/Fが8であることから、限界性能は4.5%と想定され、まだ若干の余地があると考えられる。また通信可視化ツールVampirTraceによる可視化が極めて有効であることを紹介した。
