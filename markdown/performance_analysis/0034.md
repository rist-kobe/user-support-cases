# 支援事例 No.34

## 種別

性能分析

## 課題・問題点

HPCIへの応募を検討するにあたり、計算コストが高いカーネル部分のGPUにおける性能把握
GPU対応

## 分類

性能分析

## 支援内容

まずは計算部分をテストカーネルとして切り出し、RISTが保有するGPUマシンを用いて移植作業を行い、性能分析を行った。

## 支援結果

CPUでのマルチスレッド実行時と比較し、GPUでの性能劣化とその特性等を報告した。その原因についての分析は、ハードウェアやアルゴリズムの特性などの視点から、別途検討することとなった。
