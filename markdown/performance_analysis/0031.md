# 支援事例 No.31

## 種別

性能分析

## 課題・問題点

Xeon環境で、CPU単体性能を向上させるために採取すべき情報と採取した情報から性能を向上させる方策について
移植・環境適応

## 分類

性能分析

## 支援内容

性能解析ツールを使ってホットスポットルーチンを洗い出し、更に時間計測ルーチンを使用してプログラムの各区間を測定し、行単位でホットスポットを特定した。

## 支援結果

intelコンパイラにおいて、デバッグ時のコンパイルオプションの明確化により、明らかに未定義な変数や宣言している配列の範囲をオーバーして利用している箇所を特定した。利用者から、「ifortでは初めてエラーの出し方が良く理解できた。」という反応があった。
