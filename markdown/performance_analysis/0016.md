# 支援事例 No.16

## 種別

性能分析

## 課題・問題点

2 重フーリエ変換を用いた全球気象スペクトルモデルの実行性能が、日立社製SR16000に比べて、「京」が半分程度に落ちる原因と改善策について
コード構造の改善

## 分類

並列性能分析および改善

## 支援内容

基本プロファイラによる性能評価を実施。その結果、ノード間のインバランスがある事が判明。各ランクにおいて、ループ長に違いがあるためソフトウェアパイプラインの効果にばらつきが発生し、演算にインバランスが発生することが要因と指摘

## 支援結果

インバランスの大きさが、コストの分散（最大コストのルーチンでも全体の5%程度）と報告し、極域付近を担当するノードの負荷が他ノードよりも大きく、律速となっていることを提示した。これは数値モデルの構造上（不均一なMPI分割、東西と南北で異なる通信方法）の問題で、インバランスが生じる事は避けられないと判断できた。評価結果を基に、利用者が各ランクへの格子点の割付を変更でインバランス解消の検討することとなった。
