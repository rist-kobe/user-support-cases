# 支援事例 No.7

## 種別

性能分析

## 課題・問題点

ベクトル機向けに開発された、直接法による流体コードにおいて、「京」では、FFTの前後で発生するデータの詰め替えがホットスポットであることはわかっている。今後、大規模なデータ解析を計画しており、性能の妥当性調査および性能改善案について
スレッド並列・通信最適化

## 分類

性能診断

## 支援内容

1次元分割によるflatMPIで、ノード内の自動並列化は効果なし。データ詰め替え部分がホットスポットであることを確認。OpenMPによるハイブリッド化を試行し、性能評価した結果、主要ルーチンでメモリ帯域の上限近くになっており、ほぼ妥当な性能。大規模なデータ解析では、MPIの通信コストが大きくなることが予想されるため、通信コスト削減対策として、２次元分割化案を提案。

## 支援結果

ハイブリッド並列の試行により、全体で約３倍性能が向上。
