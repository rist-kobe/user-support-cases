# 支援事例 No.32

## 種別

性能分析

## 課題・問題点

今後、GPUを有するHPCIへの応募を検討するにあたり、現状での性能把握と、特に、GPUDirectの適用による通信の高速化の見込みについて
移植・環境適応
I/O・メモリ最適化

## 分類

性能分析

## 支援内容

RISTが保有するGPUマシンを用いて、GPUDirectを用いたGPU間通信の動作確認並びに性能分析を行った。

## 支援結果

GPUDirectの適用でGPU間の通信性能が、これまでは劣ると考えられていたCPU間の通信とほぼ同等であることを確認した。これにより、TSUBAME 3.0のような大規模環境への適用の可能性を示すことができた。
