# 支援事例 No.39

## 種別

性能分析

## 課題・問題点

「富岳」上のGROMACSの使い方について
ソフトウェア評価

## 分類

性能調査

## 支援内容

Spackで提供しているGROMACSを用いて、利用者提供入力データによる並列性能の調査を行った。

## 支援結果

利用者提供入力データを使用する際に以下の点に注意する必要があることがわかった。
1)正常終了のために、実行オプション-npmeや-ddsの値を調整する必要があるケースがあった
2)実行オプション-npmeで高速化できるケースあった
3)ノード数1～8においては、ハイブリッドMPIよりフラットMPIが速度の面で有利
