# 支援事例 No.5

## 種別

性能分析

## 課題・問題点

利用者コードの「京」上で性能分析した結果を知りたい。また、性能が妥当かどうかの評価について
ソフトウェア評価

## 分類

性能診断

## 支援内容

計算の主要部分を抽出し、性能分析ツールによる演算と通信の性能解析を実施し、得られた性能情報を報告。

## 支援結果

演算部分の主要部が行列行列積（DGEMM）で、実行効率が70%と高く、妥当と判断。通信時間を含めた全体でも、実行効率が30%と高い。単体性能としては良好で、実行性能として妥当なことを確認。
