# 支援事例 No.41

## 種別

性能分析

## 課題・問題点

CT画像再構成プログラムKIERTÄÄを「富岳」で公開する前のI/O性能の確認と公開作業
I/O・メモリ最適化

## 分類

性能・環境調査

## 支援内容

中間ファイルの配置場所として、SHAREDTMP(STMP)や/worktmpなどを試した。また、サイズの違う幾つかの入力ファイルに対し、１ノードあたりのMPIプロセス数を変えてメモリサイズをプロットした。

## 支援結果

メモリサイズとI/O時間を調整したモジュールをSpackを用いて、さらには「富岳」OnDemand上から利用できるようになった。
