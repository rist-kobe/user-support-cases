# 支援事例 No.38

## 種別

性能分析

## 課題・問題点

実行時エラーの原因特定
OpenMP化した際の結果差異の原因特定
OpenMP化した際の性能評価
移植・環境適応
実行支援・動作検証

## 分類

移植支援、
性能評価

## 支援内容

不定期に発生する通信待ちによる実行時エラーの調査。
コードのバグ修正ならびに最適化による計算誤差抑制による結果検証。

## 支援結果

エラー回避ならびに結果が合致した状態で、ノード内スレッド数・プロセス数の組合せごとの性能を採取し、評価したスケーラビリティの情報を提供した。
