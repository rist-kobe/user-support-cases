# 支援事例 No.14

## 種別

性能分析

## 課題・問題点

利用者のマシン上では、実行性能は 10% 程度だが、「京」では数%の性能。性能改善するための対策について
実行支援・動作検証

## 分類

並列性能の調査

## 支援内容

性能分析した結果、演算にインバランスがあり、性能が劣化していることを確認したが、性能分析のために提供されたデータに問題があることを指摘。

## 支援結果

適切なデータで再評価すると、インバランスは発生せず、実行性能は7%出ていて、性能に問題がないことを確認。
