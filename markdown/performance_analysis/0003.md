# 支援事例 No.3

## 種別

性能分析

## 課題・問題点

「京」においてプログラムの実行時間が実行毎にブレが生じ、性能が出ない。ブレの原因を調査。
I/O・メモリ最適化

## 分類

実行時間のブレ調査

## 支援内容

ブレがなかなか再現しない中、ブレの原因がファイルI/O処理にあることを特定。さらなる性能分析で、ソルバー部分の1スレッド実行と8スレッド実行との実行時間の短縮率が、3.24倍と不十分なことを指摘。調査の結果、配列の間接参照による不連続なメモリアクセスが原因で性能が出ていないことが判明したため、ソフトウェアプリフェッチとセクタキャッシュ機能の適用を提案。

## 支援結果

実行時間のブレについては、LustreベースのファイルシステムのI/Oに起因することを利用者が了解。さらにソルバーに、ソフトウェアプリフェッチとセクタキャッシュ機能を適用した結果、約3%実行性能が向上。
