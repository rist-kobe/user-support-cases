# 支援事例 No.26

## 種別

性能分析

## 課題・問題点

スペクトル法による三次元乱流計算の高並列化（使用データ点数は、20,483点で、SX-ACEを256ノード用いて計算しているが、今後、40,963点以上に大規模化することを検討中）について、SX-ACEを1,024ノード用いた場合に、並列化効率を50%以上とできるかの検討
ソフトウェア評価

## 分類

性能評価と分析

## 支援内容

SX-ACEが持つ、区間解析機能(ftrace_region)を用いて、詳細な性能分析を行った。その結果、1,024 並列実行時に、経過時間の 54% が FFT に関連する MPI 集団通信 alltoallv である事が判明した。

## 支援結果

性能のボトルネックとなっている部分が、FFT に付随する MPI の集団通信であり、この部分に対する性能の改善は見込めないことを納得いただいた。
