# 支援事例 No.6

## 種別

性能分析

## 課題・問題点

全体コストの80%を占める行列積計算（複素数）。行列のサイズ48×48で、実行性能が20%と十分でない。その問題点の調査と、性能向上策の検討。
移植・環境適応

## 分類

性能診断

## 支援内容

性能ツールによる分析の結果、行列行列積が連なっている部分で、コンパイラの不適切な最適化により、性能が劣化していることを確認。不適切な最適化の抑止を提案。

## 支援結果

行列行列積の対象区間において、実行性能が24% から36.1% に向上したことを確認。
