# 支援事例 No.22

## 種別

性能分析

## 課題・問題点

OpenFOAM でのコンパイラーによる高速化、並列化効率の向上方法の調査依頼
移植・環境適応
ソフトウェア評価

## 分類

移植支援および性能分析

## 支援内容

当初50万cellと小型だったものから、中規模(160万cell), 大規模(970万cell)まで規模を拡大し、並列スケールの性能評価を実施。妥当なデータ規模と利用資源(MPI数)の違いによる実行効率の関係を説明。

## 支援結果

OpenFOAMの性能評価情報より、当初の小規模の160MPI並列から、目標とする大規模の1280MPIまで拡大できた。また、OpenFOAMの最適化情報提供により、640MPI並列で1.4倍の性能向上となった。
