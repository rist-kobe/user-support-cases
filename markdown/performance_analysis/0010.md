# 支援事例 No.10

## 種別

性能分析

## 課題・問題点

大規模化して実行すると Weak Scaling の性能が急速に悪化。その問題点の調査と対策について
コード構造の改善

## 分類

大規模の性能調査

## 支援内容

簡易性能分析ツール（FIPP）により数千ノードまでのプロファイリングを実施。原子数によるループは、プロセス数を増やすと、プロセス当たりの演算量は減るが、相対的にループ内部のIF文の負荷が高くなり、分割数に見合った性能とならない。原子数によるループ回数は実行中不変である点に着目し、予め各計算ノードが担当する対象原子部分リスト（部分リスト）を作成し、IF文を使わずに部分リストでループを回す方策を提案。

## 支援結果

利用者により、部分リスト利用案が採用され、Weak Scaling の性能劣化が回避された結果、大規模実行での性能が改善。
