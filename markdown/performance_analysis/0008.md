# 支援事例 No.8

## 種別

性能分析

## 課題・問題点

「京」における演算性能が利用者の環境より低い。演算性能、通信性能などを分析・評価して、性能が妥当なのか、その向上策が無いかについて
スレッド並列・通信最適化
コード構造の改善

## 分類

性能診断

## 支援内容

簡易性能分析ツールでコールツリー構造およびホットスポットの特定。詳細性能分析ツールを用いてホットスポットにおける演算性能、通信性能を評価。ホットスポットの演算部分は、C++のポインタ使用に起因して最適化されていないことを確認。対策として、指示行、修飾子による最適化促進手法を提案。また、通信が多数回な点が問題だと指摘。対策として、3次元直方体の26隣接点との通信を隣接点の共有関係を使って回数を減らすアルゴリズムを提案。

## 支援結果

最適化促進手法、アルゴリズムと性能分析手法を踏まえ、利用者が性能向上を試みる予定。

スレッド並列・通信最適化, コード構造の改善
